## 🚀 Featured Projects

### 🌤️ [skylog](https://github.com/rimmer-23/skylog) — End-to-end Weather Data Pipeline

> Collects hourly weather data from the Open-Meteo API for Prague, Kyiv and Miami, models it with **medallion architecture** (Bronze → Silver → Gold) in PostgreSQL, and visualizes it in Grafana. Fully containerized, deployed to AWS EC2 via GitHub Actions CI/CD, with nightly S3 backups — running entirely on free-tier resources.

[![View Repo](https://img.shields.io/badge/View%20Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/rimmer-23/skylog)
